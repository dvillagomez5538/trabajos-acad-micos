## Descripción

Este repositorio ha sido creado con el propósito de almacenar, organizar y gestionar los trabajos académicos desarrollados durante la asignatura, utilizando GitHub como herramienta de control de versiones.

## Objetivos

- Familiarizarse con el uso de GitHub.
- Organizar los trabajos y proyectos académicos.
- Aplicar el control de versiones mediante commits.
- Mantener un registro de las actividades desarrolladas.

## Contenido del repositorio

En este espacio se almacenarán progresivamente las tareas, investigaciones, prácticas y proyectos correspondientes a la asignatura.

## Control de versiones

Se utilizarán commits para registrar las modificaciones realizadas en los archivos y mantener un historial de cambios.
